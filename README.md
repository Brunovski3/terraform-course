# Terraform Course - Do Básico ao Avançado

## Sobre o Curso

Curso completo de Terraform com foco em infraestrutura na Azure, abordando desde os conceitos básicos até configurações avançadas com Kubernetes e provisionadores.

## Projetos

### 📁 azure-kubernetes-terraform-1
Configuração de um cluster Azure Kubernetes Service (AKS) utilizando Terraform, com aplicação de voting example.

### 📁 azure-vm-com-provisioners
Provisionamento de máquinas virtuais no Azure com uso de provisioners para configuração pós-criação.

### 📁 comandos-terraform
Lista de comandos essenciais do Terraform para gerenciamento de infraestrutura.

### 📁 bloco-terraform
Explicação detalhada da estrutura e uso de blocos no Terraform.

### 📁 azure-storage-account
Configuração de Storage Account no Azure utilizando Terraform para armazenamento de estado remoto.

## Tecnologias Utilizadas

- **Terraform** - Infrastructure as Code
- **Azure** - Cloud Provider
- **Kubernetes (AKS)** - Container Orchestration
- **Azure CLI** - Command Line Interface

## Pré-requisitos

- Terraform instalado
- Azure CLI configurado
- Conta ativa no Azure
